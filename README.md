# Первый Агент

**Агент мониторинга стажировок и митапов в Беларуси** — pet-project для портфолио в AI/automation.

> Режим работы: сбор данных → фильтрация → human-in-the-loop → уведомления + support-чат «спроси про события».

---

## Зачем этот проект

1. **Портфолио для AI-вакансий** — показать умение собирать агента, а не только пользоваться ChatGPT.
2. **Практика паттернов production-AI** — guardrails, эскалация, логи, tool calls.
3. **Личная польза** — не пропускать стажировки и митапы в BY.

Связь с ролями типа Ryze (support automation):

| Паттерн в проекте | Аналог в support |
|-------------------|------------------|
| Мониторинг источников | Мониторинг тикетов / inbox |
| FAQ «какие митапы на неделе?» | FAQ клиента |
| «Не уверен → не публикую» | Анти-галлюцинации |
| Черновик → одобрение человека | Human-in-the-loop |
| JSONL-сессия сборки в Cursor | Work sample для рекрутера |

---

## MVP (версия 0.1)

### Что умеет

- [ ] Раз в N часов обходит **2–3 источника** (см. `docs/SOURCES.md`)
- [ ] Нормализует события в единый формат (`data/events.schema.json`)
- [ ] Убирает дубли и просроченные записи
- [ ] Шлёт **черновик дайджеста** в Telegram (не публикует автоматически)
- [ ] Отвечает на вопросы в Telegram: «митапы на этой неделе», «стажировки QA»
- [ ] Если источник недоступен — пишет «не знаю», **не выдумывает**
- [ ] Пишет лог каждого прогона в `logs/`

### Что сознательно не делаем в v0.1

- Полноценный Claude Code / MCP (можно добавить в v0.2)
- Парсинг всех сайтов Беларуси
- Автопубликация без одобрения человека

---

## Политика источников (безопасность)

Домены dev[.]by, devby[.]io и связанные Telegram-ресурсы **запрещены** в коде, данных и документации. Для вакансий и стажировок используются только нейтральные платформы: rabota.by, Habr Career, LinkedIn. Подробности — `docs/SOURCES.md` и `.cursorrules`.
