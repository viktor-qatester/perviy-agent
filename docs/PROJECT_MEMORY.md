# Первый агент: состояние расписания

## Цель и решение

Мониторинг стажировок и IT-событий с Telegram-уведомлениями.
Пользователь подтвердил расписание: вторник и пятница, 05:00 Europe/Minsk.
GitHub Actions остаётся основным отправителем, локальное расписание бота
выключено по умолчанию, чтобы избежать дублей.

## Исправление 2026-10-02

`JobQueue.run_daily` в python-telegram-bot >=20 использует Sunday=0.
Исправлен справочник дней: tue=2, fri=5. Прежние значения 1,4 запускали бот
в понедельник и четверг. Добавлена проверка реальных будущих дат JobQueue,
включая время и часовой пояс. Обновлён прежний тест, закреплявший ошибочные числа.

## Ограничения и следующий шаг

В рабочей среде нет доступа к процессу бота на VPS. Его `.env`, окружение,
другие автоматические запуски и перезапуск ещё требуют проверки на самом сервере.
Инструкция: `docs/SCHEDULE_DEPLOYMENT.md`. GitHub Actions может задерживать запуск;
точное время доставки 05:00 не гарантировано.
