## Компоненты

### 1. Sources (`src/sources/`)

Каждый источник реализует интерфейс:

```python
class Source(Protocol):
    name: str
    def fetch(self) -> list[Event]: ...
```

MVP: `manual_feed.py` — JSON/CSV с событиями, которые вы добавляете вручную или полуавтоматом.

Позже: RSS (профильные IT-сообщества, community channels), парсинг страниц митапов.

### 2. Collector Agent (`src/agents/collector.py`)

- Вызывает все источники
- Нормализует в `Event` (см. schema)
- Дедупликация по `(title, date, url)`
- Фильтр: `date >= today`
- Логирует ошибки источников **без** подмены выдуманными событиями

### 3. Digest Agent (`src/agents/digest.py`)

- Берёт свежие события за период (неделя / 3 дня)
- LLM формирует **черновик** текста (не финальную публикацию)
- Промпт: только факты из JSON, ссылки обязательны, «если данных нет — так и напиши»

### 4. Support Agent (`src/agents/support.py`)

Support-паттерн для портфолио:

| Intent | Пример вопроса | Действие |
|--------|----------------|----------|
| `list_meetups` | «Митапы на этой неделе» | фильтр + ответ со ссылками |
| `list_internships` | «Стажировки для QA» | фильтр по тегам |
| `unknown` | всё остальное | «Не уверен, уточню / эскалация» |
| `source_failed` | — | честный ответ «источник недоступен» |

Guardrails:
- ответ только из `events.json`
- каждое событие с `source_url`
- confidence < порога → «не знаю»

### 5. Notifier (`src/notifiers/telegram.py`)

v0.1: print в консоль (dry-run)

v0.2:
- отправка черновика админу
- кнопки: ✅ Опубликовать / ✏️ Править / ❌ Отмена

## Human-in-the-loop (HITL)

```
Agent нашёл 3 события
        ↓
Сформировал черновик
        ↓
Отправил ВАМ в Telegram
        ↓
Вы: Опубликовать / Править / Отмена
        ↓
Только после ✅ — сообщение подписчикам
```

Это тот же паттерн, что Ryze использует для изменений в рекламных аккаунтах.

## Логирование

Каждый прогон → `logs/run-YYYYMMDD-HHMMSS.json`:

```json
{
  "started_at": "2026-07-30T09:00:00+03:00",
  "sources_ok": ["manual_feed"],
  "sources_failed": [],
  "events_found": 5,
  "events_new": 2,
  "digest_preview": "...",
  "errors": []
}
```

Для отладки агента (и для JSONL work sample) — видно, где споткнулся pipeline.
